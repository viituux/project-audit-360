# Project Evolution 360 — Skill para OpenAI Codex

Copie esta pasta em `.agents/skills/project-evolution-360/` na raiz de um repositório acessível ao Codex. Abra uma nova tarefa na branch com a Skill.

## Modos
- `$project-evolution-360 cycle`: mapeamento, auditoria e plano (somente leitura).
- `$project-evolution-360 audit-full`: auditoria de código/produto/segurança/QA.
- `$project-evolution-360 audit-design`: revisão visual e crítica de estética genérica.
- `$project-evolution-360 audit-ux`: jornadas, acessibilidade e responsividade.
- `$project-evolution-360 design-fix`: alterações de UX/UI autorizadas.
- `$project-evolution-360 fix`: correções específicas autorizadas.
- `$project-evolution-360 verify`: validação após mudanças.

A Skill não trabalha sozinha nem garante um projeto perfeito. Avaliação visual requer aplicação renderizada ou screenshots. Não inclua credenciais no repositório.
